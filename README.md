# 🎵 나만의 AI 음악 추천기

이 프로젝트는 사용자의 현재 기분과 취향에 맞는 앨범을 추천해주는 Streamlit 기반의 웹 애플리케이션입니다.

다양한 음악적 특징(템포, 에너지, 분위기 등)을 조절하여 개인화된 추천을 받을 수 있으며, Spotify와 MusicBrainz API를 연동하여 풍부한 앨범 정보를 제공합니다.

## ✨ 주요 기능 상세

이 앱은 단순한 추천을 넘어, 음악을 발견하는 재미와 편리한 관리 기능을 제공합니다.

### 1. 다차원적인 기분 분석을 통한 정교한 추천

사용자의 복합적인 기분과 상황을 5가지 차원으로 나누어 입력받고, 이를 바탕으로 정교한 추천을 제공합니다.

-   **템포, 에너지, 분위기**: "빠르고 신나지만 어두운" 음악처럼 복합적인 조건을 슬라이더로 간단히 설정할 수 있습니다.
-   **감상 시간 및 장르**: 원하는 감상 시간과 선호하는 장르 카테고리를 지정하여 추천의 정확도를 높일 수 있습니다.
-   **적합도 점수**: 앱은 각 앨범이 사용자의 조건과 얼마나 일치하는지 '적합도 점수'로 계산하여 가장 적합한 상위 3개의 앨범을 제시합니다.

### 2. 스마트한 외부 API 연동

-   **Spotify**: 추천된 앨범의 커버 아트를 즉시 보여주며, 'Spotify에서 듣기' 버튼을 통해 바로 감상 페이지로 이동할 수 있습니다.
-   **MusicBrainz**: 앨범의 장르 정보를 자동으로 가져와 필터링에 사용합니다. 특히, 아티스트와 앨범 제목으로 검색 시 가장 정확한 결과를 찾기 위한 내부 스코어링 로직이 구현되어 있습니다.

### 3. 나만의 추천 데이터베이스 구축

기본 목록에 없는 앨범도 직접 추가하여 자신만의 추천 데이터베이스를 만들 수 있습니다.

-   **편리한 앨범 검색**: 아티스트 이름만 입력하면 MusicBrainz DB에서 해당 아티스트의 앨범 목록을 자동으로 불러와, 정확한 앨범 제목을 쉽게 선택할 수 있습니다.
-   **특성 직접 정의**: 추가하려는 앨범의 템포, 에너지, 분위기 등의 음악적 특징을 직접 설정하여 추천 로직에 반영할 수 있습니다.
-   **목록 관리**: 추가한 앨범은 언제든지 목록에서 확인하고 삭제할 수 있습니다.

### 4. 지루할 틈 없는 상호작용형 대기 화면

데이터를 분석하는 동안 사용자가 지루하지 않도록 두 가지 모드의 대기 화면을 제공합니다.

-   **음악 상식 모드**: "알고 계셨나요?" 형식으로 다양한 음악 상식을 10초마다 보여줍니다.
-   **음악 퀴즈 모드**: 간단한 음악 퀴즈가 출제되고, 5초 후에 정답이 공개되는 방식으로 재미를 더합니다.

## ⚙️ 설치 및 실행 방법

이 프로젝트는 Python 패키지 관리 도구인 `uv`를 사용하여 환경을 구성합니다.

### 1. 사전 준비

- **Python**: Python 3.8 이상이 설치되어 있어야 합니다.
- **uv 설치**: 터미널(명령 프롬프트)에 아래 명령어를 입력하여 `uv`를 설치합니다.
  ```bash
  pip install uv
  ```
- **Spotify API 키**:
    1. [Spotify for Developers](https://developer.spotify.com/dashboard/)에 접속하여 로그인 후, `Create App` 버튼을 눌러 새 앱을 생성합니다.
    2. 생성된 앱 대시보드에서 `Client ID`와 `Client Secret`을 복사합니다.
    3. `Edit Settings`를 누르고, `Redirect URIs` 항목에 `http://127.0.0.1:8888`을 추가하고 저장합니다.
    4. `Fin_music_app.py` 파일 상단의 `client_id`와 `client_secret` 변수 값을 자신의 키로 교체해야 합니다.

### 2. 프로젝트 실행

1.  **프로젝트 폴더로 이동**: 터미널에서 이 저장소(repository)를 복제(clone)하거나 다운로드한 폴더로 이동합니다.
    ```bash
    # 예: 저장소 이름이 'music-app'이라면 cd music-app 과 같이 이동합니다.
    cd /path/to/your-project-folder
    ```

2.  **가상 환경 생성 및 패키지 설치 (최초 1회)**
    - 아래 명령어를 실행하여 가상 환경을 만들고 필요한 모든 패키지를 설치합니다.
    ```bash
    uv sync
    ```

3.  **앱 실행**
    - 설치가 완료되면, 아래 명령어로 앱을 실행합니다.
    ```bash
    uv run streamlit run Fin_music_app.py
    ```
